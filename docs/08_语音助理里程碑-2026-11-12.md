## 1. M2 · 助理服务(app_assist 组件 + ai_session_announce)

- **SNTP 时间底座**: WiFi 就绪自动校时(ntp.aliyun.com), TZ=UTC+8;
  `CUBE_EVT_TIME_SYNCED`; 未同步时拒绝设定提醒(防错时钟)。
- **琐事/提醒统一存储**: NVS("assist" 命名空间, blob 布局, 满则淘汰
  最旧), RAM 镜像 + 互斥; 断电不丢。
- **LLM 技能**(慢线 FC, 注册表 8→12 容量):
  `memo.add` / `reminder.add` / `assist.list` / `assist.remove`。
  reminder.add 的口语时间("明天上午十点")由 LLM 换算成绝对时间
  `YYYY-MM-DD HH:MM` 下发(system prompt 每轮注入当前时间作参照)。
- **到点播报**: 1s 调度 → `CUBE_EVT_REMINDER_FIRED` →
  `ai_session_announce()` 带外出声(快线在位走 omni 同音色, 否则
  cosyvoice; 会话忙时挂起, 轮结束自动补播)。
- **板上实测**: 板测脚本 12/12 PASS(含 "明天上午十点"→`10:00` 正确入库)。

## 2. M3 · 灵魂内核(app_soul 组件, 移植 Kaleido)

- **纯 C 三组件**(自 Kaleido 整体拷贝, 保留 kd/ke/ki 前缀便于同步):
  - `soul_drive`(三驱力内稳态 social/stim/rest, 1Hz 代谢+事件脉冲)
  - `soul_emotion`(九维感受态: valence/arousal/urgency/…/social_bond;
    一阶低通+迟滞门; LLM 禁直写, 唯一合法回写=mood 标签重评价 ±0.2)
  - `soul_ignition`(点火五因子+防打扰门; soul_think 消费, 默认关)
- **编排层 soul.c**: 1Hz 单写者 tick(kd→ke→快照); 事件漏斗
  (轮成败/打断/人声, 优先级消费); 开机静默 60s。
- **每轮 LLM 注入**: `[内在状态] 心情/活力/表达冲动 + mood 标签协议`
  (回复尾部 `<mood d="+0.1"/>`, 出声前剥离并回写情感引擎) +
  TTS 语速/音高随情绪调制(0.8-1.2 / ±2 半音)。
- **记忆轻量版 soul_mem**(NVS, 60 条): 每轮记 {用户句+回复首句+时间+
  情绪定点}, 检索分 = 0.5·recency + 0.3·strength(越回忆越牢) +
  0.2·2-gram 匹配; prompt 注入 top-3, 空库显式空态(防幻觉纪律)。
- **主动交互 soul_think**(Kconfig `ESP_CUBE_SOUL_PROACTIVE`, 默认 n):
  触发闸+深思单句(JSON 协议拒非降级)+防打扰全套(勿扰 23-8 点/日配额
  4/冷静期 30min 被忽略 ×2/开机静默 3min/5min 去重)。
- **板上实测**: 时间解析+记忆记录+二次提问记忆生效;
  排掉一个深坑 —— `%.4s` 字节截断撕裂 UTF-8 续字节 → system prompt
  非法 UTF-8 → DashScope 400(arousal 中档"中等"必现, 已修+留档)。

## 3. M4 · 角色化 UI(全屏表情常驻, 2026-11-12 用户定案)

- **主界面 = 常驻全屏动画表情**(EFC 460×460): 设备状态唯一表达;
  帧速映射会话状态(聆听 55ms/思考 130ms/播报 38ms), 情绪底色圆随
  soul anim_tag 七色变化, 聆听态呼吸。
- **下滑 = 状态栏面板**: 时钟/日期/网络/供电/音量条(可拖动, 自绘
  track+fill); 8s 无操作自动收回; 圆屏安全区居中布局。
- **上滑 = AI 状态面板**: 心情词+tag、心情/活力/联结三条、对话字幕、
  待办条(下一条提醒倒计时)。
- **移除**: 频谱直线(ui_render)/歌词飞行(ui_lyrics)/音量 HUD/
  场景机 —— 单屏 + 双面板。
- **手势**: 上下滑开合面板、左右滑切台、单击收起; sim 已合成输入
  验证全通(sim demo 时间线含面板步骤, 188fps, UI 负载 0.1ms/帧)。
- **无触摸期入口**: `panel <1|2|0>` CLI 命令(model.panel_req 命令
  通道, 语音开面板可复用); 板上触摸硬件/驱动未接入(历史记录
  P4C5 无触摸), 若硬件有触摸(告知控制器型号)我再接 indev。
