# 04 音乐平台正规接入方案调研(APK/硬件视角)

> 调研日期:2026-11-09 | 方法:四路并行网络调研(官方文档优先,逐条标注来源与时效)
> 问题:**正规途径**(官方授权/官方SDK,不逆向、不爬虫、不破解)让 EspCube 或自研
> Android APK 使用国内音乐平台(QQ音乐、网易云等)正版曲库,有哪些路?
>
> 结论先行:国内正版曲库的"门"全部开在**企业商务侧**,个人开发者没有任何曲库
> API 入口。"APK 接入"的现实正规形态只有三种:
> ① 手机**官方 App → 蓝牙 A2DP → 音箱**(零授权,即用,合规)——推荐主线;
> ② 自研 APK 做**控制端/配网端**(不是曲库客户端;唯一 API 例外是 Apple Music
>    MusicKit for Android,国区可用);
> ③ 未来公司化后走 **QPlay Auth / 网易云开放平台 / 咪咕开放平台**商务合作。

## 1. 平台侧官方入口盘点

### 1.1 腾讯音乐系 TME(QQ音乐 / 酷狗 / 酷我)

| 途径 | 对象要求 | 内容授权 | 当前状态 | 可行性 |
|---|---|---|---|---|
| 腾讯云小微硬件开放平台 | 企业资质+内测+寄样机审核+按台数付费 | QQ音乐曲库(商务签约) | 运营中,入口迁至微信体系(xiaowei.weixin.qq.com,文档2026-04更新) | 低(SDK 面向 Linux/Android,ESP32 承载不了授权链路) |
| **QQ音乐开发者平台**(y.qq.com/music_developer) | 厂商,商务申请(AppID/私钥制) | **QPlay Auth**:用户经微信/QQ/QQ音乐App授权,合作产品获取QQ音乐App音乐流并控制 | 存在;2026-07 官方宣布"低门槛、短周期、可闭环"升级,条件仍商务洽制 | **中**(公司化后的首选谈判对象) |
| QPlay 设备认证 | 硬件厂商,NDA+全套证照+百佳泰实验室测试 | QQ音乐App局域网推流 | 活跃(2025-07 Sonos Arc Ultra 获臻品认证,推进 QPlay 3.0) | 低(协议保密,个人无法接入) |
| TME 车载/爱听卓乐 B 端曲库 | 车厂/Tier1/企业客户 | 商用曲库 API(华为/小米/蔚来等客户) | 运营中,封闭 | 中(企业商务洽,门槛未公开) |
| QQ音乐/酷狗"开放平台" | 个人 | 仅内容创作者入驻,无播放 API | 运营中 | 不可行(定位不符) |
| 小微个人开发者 secret | 个人 | 无版权内容,明文"仅限学习、严禁商用" | 运营中 | 不可行 |

来源:腾讯云小微文档(cloud.tencent.com/document/product/645/93493)、微信小微设备接入
(developers.weixin.qq.com/doc/xwei/xiaowei-devices/Guide.html,2026-04)、QPlay 认证页
(music.qq.com/y/static/qplay/qplay_coop.html)、百佳泰 QPlay 实验室页、Matrix 矩声 2024-11
原生集成 QQ音乐的厂商新闻(行业从推流向原生集成演进的风向标)。

**要点:QPlay Auth 是与"APK 接入"最贴题的官方机制**——它是账号授权模式
(用户自己的账号、自己的会员授权给设备),不是平台白送曲库;技术上跑在嵌入式
设备上可行(QPlay 早期案例),但申请主体必须是公司。

### 1.2 网易云音乐

- **没有面向个人的播放 API**。官方"开放"体系是内容进网易的方向:网易音乐人
  入驻(个人可申请)、公司/机构入驻为邀请制、云村交易所(曲库版权交易撮合)。
- 车机/音箱为 B2B 商务:50+ 车企合作、2025-05 手机/车机会员"一号打通";
  网易云开放平台(developer.music.163.com)面向智能音箱/车机以 API 开放歌单/
  推荐/播客,并已向 AI Agent 开放(与宇树机器人语音点歌合作),但资质与计费
  页面对外内容为空,需商务咨询。
- 社区流行的 NeteaseCloudMusicApi、Music Assistant 集成全部基于**逆向接口**,
  原仓库已删除,不属于正规途径,商用有法律与账号封禁风险。

### 1.3 咪咕音乐(中国移动)——唯一"流程公开"的硬件入口

- open.migu.cn 实测为"咪咕音乐开放能力"平台,能力列表**官方写明支持硬件接入
  (智能音箱、智能家居、车载音乐、可穿戴)**,流程公开:注册→公司资质审核→
  开发→平台测试→签约商用;宣称 4000万+ 正版曲库。
- 但仍需**公司资质**审核+签约,个人身份走不通;分成模式面向会员/数字专辑分发。

### 1.4 其他平台一览

| 平台 | 正规入口 | 结论 |
|---|---|---|
| 汽水音乐(字节) | 无任何公开 API/硬件计划(仅车企商务:理想 2025-12、比亚迪 2026-01) | 个人无入口 |
| 酷我(TME) | 无公开开放平台 | 无入口 |
| 千千音乐(太合) | open.taihe.com 已无法解析(2026-11 实测 ENOTFOUND) | 入口失效 |
| 华为音乐 | 仅自有生态;开发者联盟商务签约(音频内容合作协议/HiCar SDK) | 企业路线 |
| 荣耀音乐 | 曲库来自网易云厂商级合作 | 企业路线 |
| **Apple Music 国区** | **MusicKit for Android SDK**:个人开发者($99/年 Apple Developer)即可在自研 APK 内用用户自己的 Apple ID + 订阅播放 | **个人唯一可拿到的官方播放 API** |

## 2. 智能音箱生态"认证换版权"路线评估(结论:换不来)

| 生态 | 硬件认证现状 | 认证能拿到什么 | 音乐在哪 |
|---|---|---|---|
| 小度 DuerOS | 存活,DCS SDK 免费开放,IDK 套件可申请(参考设计已"停止申请") | 语音能力/技能框架 | 曲库绑定小度音箱音乐会员(年费约109–159元,QQ音乐/酷狗/酷我三选一),不对第三方设备开放 |
| 天猫精灵 AliGenie | 四家中公开流程最清楚(模组接入+SDK,五步流程,需官方认证) | 语音模组/技能 | 虾米 2021 关停后转外部合作曲库;团队 2025-01 并入夸克,战略转 AI 眼镜,开放政策连续性存疑 |
| 小米小爱 | 开放的是技能/MIoT 控制(让设备"被小爱控制"),不开放整机语音+曲库 | 技能层 | 音箱会员捆绑小米/QQ/网易云三曲库,系 B 端合作,无白牌先例 |
| 腾讯云小微 | 企业内测+签约 | **唯一明确提供音乐内容 API 的生态**(Rokid 2018 先例) | 按台数付费购买 QQ音乐服务 |

行业背景:2021-07 监管要求腾讯放弃独家版权后,曲库独家壁垒解除,但授权仍是

洛图科技),四家生态均在收缩自有开放力度。**为拿版权去做生态认证是目标错配:
认证给语音,不给音乐。**

## 3. 免授权桥接技术路线(手机 App 作音源)

版权责任转移给用户侧音源(用户在自己的官方 App 里听自己的会员),设备只是
扬声器/控制目标——这是飞傲(预装合作App+蓝牙)、小智系厂商、DIY 社区的事实
标准做法,个人使用合规。

### 3.1 A2DP sink + AVRCP 元数据 —— 成熟度:成熟,**优先做**

- ESP-IDF 官方支持完整链路:`esp_avrc_ct_send_metadata_cmd` 可取
  TITLE/ARTIST/ALBUM/TRACK_NUM/GENRE/PLAYING_TIME(封面需 AVRCP 1.6 +
  Cover Art 特性);a2dp_sink 官方示例(master)含完整元数据分片拼装流程;
  absolute volume 双向支持(CT 下发 0–0x7f,TG 侧可上报本地音量变化)。
  角色:音箱(A2DP sink)= AVRCP TG,手机 = CT。
- 国内 App 实测证据充分:QQ音乐/网易云/酷狗/酷我/咪咕经车载蓝牙均可上屏
  曲名/歌手(汽车之家、车连易实测帖);部分需在 App 内开"QPlay与车载音乐/
  蓝牙显示"开关(荣耀社区官方排查帖);封面需手机开发者选项 AVRCP 1.6;
  歌词不在 AVRCP 标准字段(各家私有方案)。
- 共存风险:ESP32 单射频 WiFi/BT 时分复用,WiFi 大流量可能挤占 A2DP
  (官方 coexist 文档);**S31 WiFi6+经典蓝牙共存表现无公开资料,需真机压测**
  (下载电台 vs A2DP 播放并发)。
- 参考:ESP-IDF a2dp_sink 示例、pschatzmann/ESP32-A2DP(2.8k stars,
  Apache-2.0,持续维护,仅经典蓝牙芯片)。

### 3.2 DLNA/UPnP renderer —— 实验性,**缓做/不做**

- ESP32 无成熟开源 renderer(GitHub 搜索仅 1 个个人项目;gmrender-resurrect
  等均为 Linux 方案);网易云 Android 的 DLNA 入口近年劣化、iOS 明确不支持;
  QQ音乐走 QPlay 体系,VIP/加密歌曲(QMC/MFLAC)投 DLNA 失败或自动跳过
  (社区实测,无官方白皮书)。投入产出比低。

### 3.3 自研 Companion APK(控制端)—— 成熟度:成熟,**次优先**

- **定位必须正确:APK 是配网+控制端,不是曲库客户端**。自研 APK 拿不到
  QQ音乐/网易云的流(无个人 API);唯一例外 Apple Music MusicKit(1.4 节)。
- 配网:espressif/network_provisioning(BLE/SoftAP/BluFi,官方组件,1.3.2+),
  现成手机端 "ESP BLE Provisioning" App 可先用,自研 APK 复用其 prov 协议。
- 控制:局域网 **WebSocket(状态推送+控制)为主、REST 兜底**;
  xiaozhi-esp32 的 WebSocket 协议文档与开源手机客户端可直接参考;MQTT 留给
  未来 Home Assistant 集成。
- 音频:APK 内嵌轻量 HTTP server 推流(ESP32-audioI2S / esp_http_client 侧
  成熟),追求低延迟再上 RTP/UDP;RTSP 无成熟参考,不做。

### 3.4 AirPlay / Google Cast —— 不做

- AirPlay:airplay-esp32(651 stars,活跃)可用但**非商用许可**,且国内音乐
  App 的 Android 端无 AirPlay 投播入口(只有 iOS 系统级)。
- Google Cast:receiver SDK 专有需 Google 认证,无 ESP32 开源 receiver,
  国内 App 不支持。均不做。

## 4. 行业模式与成本量级

- C 端:智能音箱"买音箱再买音乐会员"年费约 109–159 元(中国青年报 2023-09)。
- B 端:无公开统一价;行业惯例按协定收入分成+版权摊销(内容分成+版权成本
  约占平台总成本 30–40%,喜马拉雅招股材料);直接买断曲库年费**百万级起步**
  (由会员定价与分成模式推算,无公开报价),创业级不可行。
- 时间:技术接入以周计;内容授权是商务谈判,**以季度计(乐观 3–6 个月)**,
  结果不可预期。

## 5. EspCube 决策建议

**路线图(按优先级):**

1. **现在(个人,立即可做)**:A2DP sink 补齐 AVRCP——元数据(曲名/歌手)上屏
   + absolute volume。零授权、即用,顺带解决 M3"曲名显示"需求。
   需真机压测:WiFi 电台下载与 A2DP 并发(S31 共存表现无公开资料)。
2. **接屏后(可选)**:自研 Companion APK 原型——network_provisioning BLE 配网
   + WebSocket 控制 + HTTP 推流(高码率音源通道,弥补蓝牙带宽)。
   想要正版点播 API,只有 Apple Music MusicKit 一条(国区可用)。
3. **未来公司化(不是现在)**:按"QQ音乐开发者平台(QPlay Auth)→ 网易云开放
   平台 → 咪咕开放平台"顺序商务洽谈;把"正版播放"做成里程碑而非前置条件。
4. **M4 AI DJ 点歌**:无授权前不做正版曲库点播;继续"电台 + AI 播报 +
   用户蓝牙自播"组合,**商用固件严禁内置爬源/免费音源接口**(版权风险自担)。

**明确不推荐**:逆向 API(NeteaseCloudMusicApi 及镜像、qishui-api 等)——
违反平台条款,账号封禁+法律风险,且接口随时失效;DuerOS/AliGenie 整机认证
(换不来曲库);DLNA 正版投播(生态缺失+平台限制);Google Cast(不可行)。

**未找到公开信息的点**(后续如需再查):S31 官方 datasheet(公开渠道仅
xiaozhi-esp32 README 提及,"S31 需 IDF 6.1+"与我们实机一致);S31 WiFi6+A2DP
共存实测;DuerOS/AliGenie 认证费用细则;网易云开放平台计费条款。
