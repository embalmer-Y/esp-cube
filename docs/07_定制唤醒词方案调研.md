# 07 · 定制唤醒词方案调研(2026-11-12)

> **修订(2026-11-12 用户裁决: 必须开源方案)**:
> **主路线 = microWakeWord(B, Apache-2.0 训练+运行时全开源自托管)**,
> **快轨 = onnx-wakeword/voicute(A, 推理 MIT, 免费云训练 15 分钟出模型,
> 作质量/性能基线试点)** —— 两者板上运行时同底座(esp-tflite-micro
> 1.4.1 + esp-nn, 官方支持 P4/S31), 集成层共用(KWS 槽位抽象)。
> 乐鑫官方免费 TTS 通道(esp-sr issue #88)降为备选(模型非开源)。
> 过渡期 = 预置词(现用 你好小智)。详见 §7 开源双轨实施计划。

## 0. 现状

- 引擎: esp-sr 2.6.0 WakeNet9(P4 支持 wn9/wn9l/wn10), 模型在 `model` 分区
- 现用词: `CONFIG_SR_WN_WN9_NIHAOXIAOZHI_TTS=y`(你好小智, TTS 鲁棒变体,
  TTS 合成音也可唤醒 —— 自测 harness 依赖此特性)
- 加载: menuconfig 勾选(可多选打包, 运行时 `set_wakenet()` 切换);
  **定制模型免改源码路径 = `ESP_SR_EXTERNAL_MODEL_PATH`**(2.6.0 起构建期
  自动打包, wakeword_list.md 官方两步法)
- P4 资源余量: wn9 2ch = RAM 16KB + PSRAM 324KB, 2.6ms/帧(400MHz),
  CPU 占用低, 换词无资源压力

## 2. 路线 A 详情(主路线)

- 入口: esp-sr issue #88 "Training Wake Words by TTS sample"(置顶, 持续
  处理中, 2026-11 仍有 P4+esp-sr 2.6.1 用户成功案例)
- 门槛(2024-08 起): 附**进行中项目链接+简介**, 或该词获 5+ 👍
- 词要求: **3-5 音节**(双音节易误触发有一律拒绝先例); 商标权责自负
- 交付: 模型合入 esp-sr 后续版本公开发布 + FAR/RAR 测试报告
  (参考 Hey Willow 案例: FAR 1次/8h, RAR 88%, 迭代过两轮)
- 集成: 模型目录 → `ESP_SR_EXTERNAL_MODEL_PATH` → 构建自动打包, AFE
  管线零改动

**提交模板(定词后可用)**:
```
Title: Wake word request: "<品牌词>" (Chinese, 4 syllables)
Body:
- Wake word: <品牌词>(拼音: xxx)
- Language: Chinese (Mandarin)
- Project: <EspCube 项目链接> — a desktop voice assistant on ESP32-P4
  (esp-sr 2.6.0, WakeNet9, currently using wn9_nihaoxiaozhi_tts)
- Preferred engine: wn9 (+wn10 if possible)
I agree to the Wake Word Submission Agreement; the word is our own brand
and we take trademark responsibility.
```

## 3. 定词建议(用户决策项)

- 3-5 音节、音节区分度高(开音节多、声调组合差异大)优于双音节
- 避开高频日常短语(误唤醒)与现有预置词(你好小智/小爱同学等)
- 定词后动作链: issue #88 提交 → 等模型 → external path 打包 → 板上验收
  门禁(Kaleido 口径): 真人 ≥9/10、TTS 机器音命中、自唤醒泄漏 ≤1/10、
  CPU 增量 ≤10%

## 4. 过渡期(路线 C)切换方法

menuconfig → ESP Speech Recognition → Load Multiple Wake Words 勾选
目标词(如 wn9_hilexin / wn9_xiaoaotongxue 等, 全表见
`managed_components/espressif__esp-sr/wakeword_list.md`), 多选后运行时
`esp_srmodel → set_wakenet("wn9_xxx")` 可切换。自测 harness(stwake)
依赖 TTS 鲁棒变体(`_tts` 后缀模型), 换词时优先选带 `_tts` 的变体。

## 5. 备选轨(D/E)实施提示(如路线 A 排队太久)

- D onnx-wakeword: MIT、中文优先、voicute.com 在线生成(输入中文词→
  模型, 首次免费)、<130KB; 运行时需接 ONNX/TFLM 推理 —— 与现有 AFE
  feed 管线对接(裸 16k int16 PCM 直喂, Kaleido 已验证输入格式兼容)
- E microWakeWord: microwakeword.com 在线训练/Colab; TFLM 官方支持 P4
  (esp-tflite-micro v1.4.1 + esp-nn v1.3.0); 中文训练样本用 Piper
  `zh_CN-huayan-medium` 合成(效果自评"一言难尽", 仅作 A/B 基线)

## 7. 开源双轨实施计划(2026-11-12 深挖修订)

**硬约束裁决**: 全开源自托管 → A 只满足"推理开源"(训练闭源云托管,
issue #3 官方明示不开源; 商用需一次性模型授权), 故 **B 为唯一合规主线**,
A 作 1-2 人日快轨基线(免费生成目标词 → 板上实测 → 给 B 当质量参照)。

### A. onnx-wakeword (voicute) — 快轨
- 仓库 github.com/voicute/onnx-wakeword(MIT, 推理); 组件
  `voicute/voicute ^1.0.0`(registry); 模型 voicute.com 免费生成
  (中文 2-6 字, 15-20 分钟, INT8 TFLite ~42KB)
- 运行时: 自研 C mel(esp-dsp RFFT, 16k/32mel/hop160) + TFLM TCN
  + MultiProto head + L1-L5 五层防误触; **每 160ms 喂 16080 采样窗+RMS**,
  `recognizer_run_frame()` 出概率; S3 240MHz 实测 70-80ms/窗
- P4 状态: 依赖三件(esp-tflite-micro/esp-dsp/esp-nn)全 P4-ready,
  组件自己"代码路径可用, 未硬件实测" —— Day1 跑纯推理基准即去风险

### B. microWakeWord — 主线(全开源)
- 训练框架 github.com/OHF-Voice/micro-wake-word(Apache-2.0);
  microwakeword.com 托管训练付费且非开源, 自托管 = Colab/本地 GPU
  (basic_training_notebook, 调到可用通常数天-两周迭代)
- 中文正样本: piper-sample-generator + zh_CN-huayan-medium(多音色
  轮换+拼音/IPA 输入), 产线量 3000-5000; 负样本: HuggingFace 预生成
  + Common Voice zh-CN + 自家 TTS 播报语料(防自唤醒)
- ⚠ 商用纪律: 默认增强源含 WHAM!(CC-BY-NC) → **须剔除后训练**,
  否则模型仅限非商用
- 运行时移植: esphome/esp-micro-speech-features(40 维特征/30ms 窗,
  Apache-2.0, registry 现成) + TFLM(30ms 节拍); 从 ESPHome 组件抽出
  ≈2-4 人日(streaming_model.cpp 484 行近乎裸 TFLM);
  **ESPHome 官方把 P4 与 S31 都列为一等变体**
- 仓内模型参照: github.com/esphome/micro-wake-word-models

### 集成层(EspCube 落地设计)
1. AFE 保留、wakenet 可摘: `afe_config_init("M")` 后跳过
   add_wakenet_model(AEC/VAD/NS 与 500ms 回声闸门不动); A 喂 AFE 后
   清洁音频, B 喂 AFE 前裸 PCM(特征分布与训练一致) —— Kconfig 开关
2. KWS 槽位抽象: `kws_voicute.c`(160ms 节拍) / `kws_mww.c`(30ms 节拍)
   同一接口 {init, feed_16k_pcm, get_wake_event}, 与 wn9 三选一,
   唤醒照发 CUBE_EVT_WAKE_DETECTED(麦克风让渡逻辑零改动)
3. 模型放 SD(wake/ 目录, docs/09), 刷词免重编固件

### 顺序与门禁
- Day1: P4 上 esp-tflite-micro 纯推理基准(两案共用去风险)
- A 快轨: voicute.com 生成品牌词(免费) → 组件接入 → 门禁(真人 ≥9/10,
  自唤醒泄漏 ≤1/10, CPU 增量 ≤10%)
- B 主线训练迭代并行, 达标切默认; 素材与脚本入库(剔除 NC 源)
