## 1. 核心调研结论

### 1.1 关键澄清:主控是 ESP32-S31,不是 ESP32-S3

经核实,项目主控为乐鑫 **2026-03 发布、2026-07 量产**的新芯片 **ESP32-S31**(QFN80,模组 ESP32-S31-WROOM-3)。这一澄清是全案的基础:

- 若是 ESP32-S3:**无经典蓝牙(BR/EDR)、无 LE Audio**(官方原文 "ESP32-S3 supports Bluetooth LE only, and does not support Classic Bluetooth or LE Audio"),手机蓝牙 A2DP 不可行,必须外挂经典蓝牙协处理器;
- **ESP32-S31:蓝牙 5.4 同时含 BR/EDR(经典)与 LE Audio**,A2DP Sink 原生可行,且 WiFi 6 + 802.15.4,官方即按智能音箱定位设计。

**ESP32-S31 关键规格**(官方 datasheet v0.5 PRELIMINARY):

| 项 | 规格 |
|---|---|
| CPU | 双核 32-bit RISC-V @320MHz,每核 FPU,128-bit SIMD / AI·DSP 扩展指令 |
| 内存 | 320KB ROM + **512KB HP SRAM** + 32KB LP SRAM;**封装内 16MB/32MB Octal DDR PSRAM(专用控制器,与外设 SPI 不争带宽)** |
| 无线 | WiFi 6(20MHz)+ BT 5.4(BR/EDR 3Mbps + BLE + **LE Audio BIS/CIS/Auracast**)+ 802.15.4 |
| 音频外设 | **2× I2S**(TDM 16ch、PDM、时钟 96MHz、硬件蓝牙音频通路)、**ASRC 硬件采样率转换** |
| 显示外设 | 2× GP-SPI(主模式 80MHz,支持 4-line QSPI)、LCD_CAM(并行)、JPEG 编解码、PPA 像素加速、2D-DMA |
| USB | USB 2.0 High-Speed OTG(480Mbps)+ USB Serial/JTAG |
| GPIO | 60 个(8 LP + 52 HP) |

IDF 支持:v6.1 起提供 S31 支持(preview,正式支持自 v6.1.1;官方建议必要时用 master HEAD)。本机已装 IDF v6.1(`~/esp/esp-idf`,target=esp32s31)。

> 已知限制:HFP 通话的 SCO 音频路由到 I2S 暂未支持(IDF-15190)——不影响 A2DP 音乐与语音助手,通话类功能留待后续版本。

### 1.2 原型开发板:乐鑫官方 ESP32-S31-Function-CoreBoard-1

"ESP32-S31 Function Core Board" 与乐鑫官方开发板 **ESP32-S31-Function-CoreBoard-1** 命名一致(待实物核对,见 §3):

- 模组 ESP32-S31-WROOM-3:**16MB Flash + 16MB PSRAM**;
- **板载音频链路:数字麦克风 + ES8311 codec(I2S/I2C)+ NS4150B 3W D类功放 + 1.25mm 4Ω/3W 喇叭座** → 原型阶段音频硬件零采购;
- USB×3(Type-A OTG 主机 / USB-Serial-JTAG / USB-UART 桥)、RJ45 千兆网(本项目不用)、40pin 排针 J2(GPIO0–4、35–49、58–61、SDIO 组 GPIO20–25);
- 无屏线连接器、无 SD 卡槽 → 屏幕、电池、喇叭外设通过排针/喇叭座接入。

### 1.3 屏幕:鱼鹰光电(Osptek)2寸 QSPI AMOLED

鱼鹰光电 = Osptek Display(开源仓库 gitee/github.com/osptek)。其 2 寸方形 QSPI AMOLED 官方规格:

| 项 | 规格 |
|---|---|
| 型号 | AM200Q460460FLS1(QSPI 版);官方 **2寸方形 = 460×460**(480×480 为同厂 2.14寸/1.6寸 规格,存在混标可能,以实物 FPC 丝印为准) |
| 驱动 IC | **CO5300**(芯映),非 RM67162/SH8601 |
| 接口 | QSPI 4-line,24P FPC(附转接板 ADP-AMOLED-200-QSPI-24P) |
| 供电 | **VCI 2.7–3.6V,单 3.3V 轨即可**(CO5300 片内 boost 自产 ELVDD/ELVSS,**无需外部 7–8V AMOLED 高压轨**) |
| 亮度 | AMOLED 无背光 PWM,亮度走面板寄存器(0–255) |
| 触摸 | 官方 repo 版本无触摸;淘宝批次可能带 CST9220/CST820(待实物确认) |

软件生态:`espressif/esp_lcd_co5300` 官方组件(v2.2.0,`use_qspi_interface=1`);乐鑫官方 **ESP-Mosaico** 开发板 = "S31 + 480×480 QSPI AMOLED(CO5300)+ CST9220" 同构参考设计。鱼鹰官方例程(ESP32-S3 + IDF5 + LVGL9,含 TE 同步变体)可作移植起点。

**最低性能红线(2026-11-11 定稿,验收口径)**:**全屏刷新稳定 30fps**——
最坏情形(整屏失效区域,如歌词全屏飞入/页面切换)下连续动画 ≥30fps 且无可感知掉帧,
且**与电台播放并发**实测(排除 MSPI/PSRAM 争抢导致的解码劣化,M1 历史教训)。
带宽倒推:30fps × 423,200B/帧 = **101.6 Mbps** → 20MHz QSPI(80Mbps)**不达标**,
**PCLK ≥40MHz QSPI(160Mbps,帧传输 21.2ms,30fps 预算余量 36%)为硬性要求**
→ 杜邦线阶段以 20MHz 先点亮(妥协态),**PCB/座接后必须 40MHz 达标验收**;
挑战目标 60fps(见下方账本)。

**60Hz 可行性账本**:460×460 RGB565 一帧 ≈ 412KB;60fps ≈ **197 Mbps** 持续带宽。GP-SPI 80MHz × 4线 = 320Mbps 理论上限(≈93fps),部分刷新 + 偶数坐标对齐(CO5300 硬约束)+ TE 同步 + 双缓冲即可达成;S31 的 PSRAM 走**专用控制器**,与 LCD 的 GP-SPI 不争带宽,优于 S3(LVGL 论坛同类案例中 S3 的瓶颈正是 PSRAM 共享 MSPI)。动画密集场景按 45–60fps 预期,上板实测为准(鱼鹰例程内置 FPS 统计)。

### 1.4 蓝牙音频

- **A2DP Sink(S31 原生)**:IDF v6.1 S31 支持表明确 ✅ A2DP/AVRCP/HFP/HID/PBAP/SPP;官方例程 a2dp_sink_stream(内置 SBC 解码输出 PCM)。全手机兼容(iPhone 含)。
- **LE Audio(附加能力,非本期)**:S31 官方 ESP-BLE-AUDIO 栈(BAP/CAP/LC3 全角色)已就绪但标注 preview;2026 年手机侧 iOS 仍不支持通用 LE Audio 音频设备(仅助听器路径),Android 旗舰可发。结论:核心音乐通道走 A2DP,LE Audio 后续作为附加能力接入。
- 双射频共存:BT Classic 与 WiFi 共享 2.4G,需开启共存配置并调缓冲(风险 R5)。

### 1.5 网络音频栈

- 组件化路线:**IDF v6.1 + `esp_audio_codec`**(AAC/FLAC/OPUS 等)+ **libhelix vendored(MP3)** + 自研 HTTP/ICY 直连流 + **`esp_hls_stream`(HLS, extractor 插件模式, GMF-free)**。
- **MP3 解码器选型变更(M1.5 攻坚结论,2026-11-09)**:esp_audio_codec 的 MP3 即闭源 minimp3 派生实现,S31 实测 23ms/帧(仅 1.1×实时,必卡顿)且吞帧 ~66%(consumed 语义问题,同类先例 esp-adf-libs #75);S31 USE_ASM 汇编库不覆盖 MP3(#85);minimp3 上游存在未初始化 scratch 进 Huffman(#141)、嵌入式栈过大静默崩溃(#117) 等已知内存安全问题(本项目 SoundHelix 文件崩溃 17 次复现后回退)。libhelix 定点解码实测:数据利用率 99.96%(vs 旧 17%)、连播无卡顿、零崩溃。
- **最终根因与根治(遥测实测)**:解码器代码/三角函数表在 flash,经 MSPI 取回并与 core0 的 WiFi/BT 争抢总线 → 解码 25-27ms/帧(≈1.0× 实时,零余量);`-O3` 无改善(代码膨胀反增取指)。**将整个 libhelix(vendored 至 components/mp3_helix)通过链接脚本 noflash scheme 常驻 IRAM 后:1.9ms/帧(13.5× 提速),缓冲稳钉满格,全部历史解码怪象(23ms/16ms/吞帧)一次性消失**。代价:512KB 单 SRAM 占 44KB(空闲堆 192KB→~148KB)。遗留:接屏(LVGL 开启)后复测并发——理论余量 13× 应无碍。
- esp-adf v2.8 虽已支持 S3(IDF 5.5.3 底座),但框架重;S31 上走组件化新栈更稳。

### 1.6 语音 AI(唤醒 + 大模型)

- **esp-sr v2.6.x**:2026-05 起 S31 初步支持;**AFE 已在 S31 实测**(约 20% 单核占用),含 **AEC(支持全双工模式)/NS/VAD/AGC**——"边放音乐边拾音"(AI DJ 前提)算法层有官方支持;WakeNet10 免费(内置唤醒词免费商用,如 `wn10_nihaoxiaozhi`);MultiNet mn7_cn 本地命令词(音量/暂停/切歌等高频指令离线可用)。
- **xiaozhi-esp32 协议**(MIT):WebSocket + Opus(16k/mono/60ms 帧),事件流含 listen/stt/tts/llm/mcp/abort;自建服务端 **xinnan-tech/xiaozhi-esp32-server**(11k★)Docker 一键部署,**LLM 默认智谱 glm-4-flash(免费)**,ASR/TTS 可换,支持打断/记忆/MCP 工具;xiaozhi-esp32 固件主干已含 S31 板级定义(含 function-coreboard-1)。
- **智谱 GLM 全家桶可直连 ESP32**(mbedTLS WSS/REST):GLM-Realtime(实时语音,0.18元/分)、GLM-ASR(0.06元/分)、GLM-TTS(流式<400ms,2元/万字符)——作为第二适配器接入固件 AI 会话抽象层。
- **决策**:原型阶段固件实现统一的 AI 会话客户端(状态机),协议适配器默认 **xiaozhi(自建服务端 + GLM)**,预留 GLM-Realtime 直连适配器。用户未另作选择,此为推荐路径,可随时切换。

### 1.7 音频硬件与最终 DSP 升级路线

- **TC5FC07-04 = Peerless by Tymphany(丹麦皮亚力士)** 1.5寸全频(非 PUI Audio):4Ω,**额定 5W/峰值 10W**,灵敏度 82.8dB,Fs≈146–170Hz,Xmax±2.7mm,¥140–155/只。
- 功放匹配:3W D 类(板载 NS4150B)**刚好**——近场 0.3–0.5m 建议 0.5–1.5W 工作点;不要配 10W 级功放。低频 EQ 提升从 200–300Hz 以上做起(低于 Fs 浪费冲程);最终箱体 0.1–0.3L 密闭。
- 原型:板载 ES8311(DAC SNR 110dB,支持录音+ALC)+ NS4150B。
- **最终 DSP 方案三选**(最终板设计时定,均在 esp_codec_dev 生态内):

| 方案 | DSP 能力 | 供电 | 生态 | 备注 |
|---|---|---|---|---|
| **TAS5805M**(+ES7210录音前端) | 2×15 biquad/声道 + DRC/AGL + 热保护 | PVDD 4.5–26.4V,需 5V 升压 | **esp_codec_dev 官方驱动** | 淘宝¥3 级;SDOUT 可回传 AEC 参考;TI 生命周期需复核 |
| **AW88298** | EQ+DRC+SmartK 喇叭保护,内置 Smart Boost,5.2W | **VBAT 3.0–5.5V 单锂电直挂** | esp_codec_dev 官方(HW Verified,M5Stack CoreS3 同款) | 省 5V 轨,系统最简;单买渠道待查 |
| ADAU1761(+NS4150) | 28-bit SigmaDSP,SigmaStudio 图形化,EEPROM 自启动 | 3.3V | 无 esp 驱动(社区成熟) | 立创 ¥46;全双工含录音 |

### 1.8 电源系统(最终板设计依据,原型用 USB)

- 充电:TP4056/TP4057 + PMOS 理想二极管**负载路径管理**(充电时可用机,截止判断正确);电池包内置 DW01+FS8205 保护。
- 电量计:**CW2015**(免采样电阻,I2C,立创 ¥2–3)或 MAX17048。
- 升压:TPS61023(5V/1A,配 NS4150);若最终选 TAS5805M 则 TPS61376(2A)。**不建议 IP5306 直接贴音频**(轻载休眠 + 开关噪声)。
- 隔离:功放 PVDD 经磁珠+大电容 π 滤波;codec/麦克风模拟轨独立低噪声 LDO(ME6211/TPS7A02);功放回流、WiFi 天线电流、麦克风地分开单点接地。
- 功耗预算:播放+WiFi+亮屏 ≈ 0.8–1.5W 平均(220–400mA@3.7V);**2500mAh 续航约 6–9 小时**(满音量 3–4h;深度睡眠待机数周,S31 deep-sleep 12µA)。

## 4. 风险清单与缓解

| # | 风险 | 等级 | 缓解 |
