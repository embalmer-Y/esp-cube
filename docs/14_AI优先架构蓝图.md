## 1. 定性转折: 音响 → AI 伙伴

| | 旧(M1-M4 "cube-speaker") | 新(AI-first) |
|---|---|---|
| 产品身份 | 会说话的音箱 | 有音响能力的桌面 AI 伙伴 |
| 开机行为 | 装配层 WiFi→自动播电台(AI 不知情) | 灵魂 L0 反射决定放歌(可配置/可退避) |
| 电台/点歌 | 顶层应用, UI 直控 | **AI 能力**: 深思(L4)与评分器(L2)经统一行动词汇表驱动 |
| 深思切歌路径 | soul→main 桥→**UI 层** ui_ctl_*→player(层级违例) | soul→SOUL_ACT 总线→**app_player 自订阅**(手归位于能力层) |
| 因子汇聚 | kd/ke 散落 soul.c 内部, ki 因子现拼 | L1 因子黑板统一(评分器/深思/CLI/prompt 同源) |

不变: 用户物理直控(触摸手势/按键)仍是最高优先通道 —— 直控产生的
总线事件同时喂 L0 感知(灵魂"看见"用户操作并学习, 如手动停台=退避信号)。

[-1,1])。**单写者=soul tick**; 覆写槽(带 TTL, portMUX 保护)供台调。

```
情绪(ke): VALENCE AROUSAL URGENCY BOND ETHICS

情境:    IDLE(无互动/2h 饱和) QUIET AI_ACTIVE PLAYING PRESENCE(预留)
         NET SALIENCE(事件充值, τ≈1min 衰减) MEM_HOOK(预留)
机器状态(PhaseC 预留): BATT TEMP CHARGING TOUCH
```

kd 迁移口径(docs/13 §5.4): social/stim 误差即"水库缺口"直入黑板;
**rest 保留在 kd/ke 内部**(其动力学仍喂 ke, 黑板不暴露)——Phase C
机器状态能量维接管后再删, 避免中间态情感断链。

## 5. L2 评分器 + L3 行为(soul_behavior.h)

```c
score(b) = w(b) × ∏ curve(factor)      /* RISE/FALL/BAND ×k 钳位[0,1] */
仲裁: 过阈值 ∧ 过冷却 ∧ 未退避 → 候选集 → 按 score 加权随机 WTA
      (xorshift 确定性 RNG, 可宿主单测) → 执行器(注入) → 记 last_fire
退避 defer(name, s): 外部抑制(用户手动停台→radio_start 退避 2h)
```

v1 行为表(全部已存在的执行末端, 零新能力):

| name | 考虑项 | 执行 | 阈值/冷却 | 语义 |
|---|---|---|---|---|
| radio_start | STIM↑ PLAYING↓ QUIET↓ AI_ACTIVE↓ | SOUL_ACT music:play | 0.35/30min | 无聊自娱放歌(开机首播走 L0 反射) |
| radio_stop | QUIET↑ PLAYING↑ | music:stop | 0.80/60min | 勿扰时段礼让静音(产品新行为) |
| self_face | IDLE↑ M_SOCIAL↑ AI_ACTIVE↓ | kind1 face(yawn/ponder/music) | 0.50/8min | 独处自娱微表情("存在感") |

预留位(Phase B/C 填动力学): greet(在场跃迁)/talk(深思强触发)/
stim_game(高刺激收敛)。ki 深思路径**不经评分器**(L4 直达词汇表),
两者共享同一词汇表与执行器 —— 命令式(会话技能)与自主式(灵魂)同末端。
