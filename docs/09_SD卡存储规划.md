# 09 · SD 卡存储规划(2026-11-12 定案)

> ⚠ 历史快照(2026-11-12): SDMMC 口径已被 docs/10 定案与实际实现(SDSPI, app_storage.c)覆盖; 记忆目录口径已被 docs/16/17 §8.1 与 docs/21 覆盖(v1/personas/<key>/memory/episodes.tsv)。

> 记忆系统强制 SD 卡(用户裁决)。底板 TF 卡槽(microSD, SDMMC slot0
> GPIO39-44, DET=45)与 C5 WiFi(slot1 GPIO14-19)**独立并发**——Kaleido
> 26 号调研三重验证。落地 = `app_storage` 组件: FATFS 挂载 `/sdcard`,
> 无卡优雅降级(记忆回退 NVS 60 条 / 素材回退 flash 内置)。

## 1. 目录规划(`/sdcard`)

| 目录 | 内容 | 消费方 | 回退 |
|---|---|---|---|
| `mem/episodes.jsonl` | **情节记忆主存储**(TSV 行: 时间/seq/强度/情绪定点/用户句/回复首句), 上限 **512 条**(NVS 回退时 60) | soul_mem(SD 后端, 记录/淘汰后全量回写) | NVS "soulmem" |
| `mem/raw/YYYY-MM-DD.log` | 对话原文逐轮(ASR 全文+回复全文, 只增不删; 隐私口径见 §3) | 预留(未实装) | — |
| `face/*.efc` | **表情素材库**: `idle/listen/think/speak.efc` + `mood/<tag>.efc`(happy…sleepy 七情绪)——状态→片段查表替代当前单 clip 演示 | ui_face(M4+; flash 余量 ~0.8MB 装不下多段, SD 解决) | flash 内置 giphy_z |
| `wake/` | **开源唤醒词模型**(onnx/tflite + threshold 配置 json) | 开源 KWS 运行时(M5 前置; 见 docs/07 开源路线) | esp-sr wn9 预置词 |
| `voice/ref.wav` | 复刻参考音频 10-30s(M5, 用户 pending) | tools/clone_voice.py 流程 | 预置音色 |
| `etc/persona.json` | 人格配置: 音色 id / 主动度 0-10 / 勿扰时段 / 名字(**app/web 配置页的落点**, 设备端不做设置界面) | soul/ai_session 启动加载 | 编译期默认 |
| `logs/` | 运行日志留痕/崩溃复盘(可选 esp_log 文件通道) | 预留 | 串口 |
| `ota/`(可选) | 升级包缓存 | 预留 | — |

## 2. 已实装(本批)

- `app_storage`: SDMMC 4-bit 挂载 + 目录骨架 + `read/write(原子 rename)/append`
  + `CUBE_EVT_SD_READY`; **绝不格式化用户卡**
- `soul_mem` 双后端: SD 在位 → jsonl 512 条; 无卡 → NVS 60 条(原路径)
- Kconfig `ESP_CUBE_ENABLE_SD`(P4C5 默认 y); FATFS 长文件名已开
- 引脚: `BOARD_PIN_TF_*`(board_pins_p4c5.h)

## 3. 边界与纪律

- **隐私**: mem/raw 对话原文默认**不落盘**(实装时加 persona.json 开关,
  默认关); episodes 只存摘要级(用户句截 96B), SD 卡可拔即带走
- **写入频度**: 记忆全量回写 87KB/次(记录或淘汰时), FAT 卡寿命充裕;
  后续量大改 jsonl 追加 + 定期压实(Kaleido 覆盖表方案)
- **掉电**: 原子写(tmp+rename)保证 jsonl 不撕裂; 丢最后一轮记忆可接受
- **卡规格**: ≥8GB Class10/FAT32(exFAT 未启用); 热插拔不支持
  (上电探测一次; 重新插卡需重启)
