# 13 · 动机、内部状态与决策架构调研(2026-11-13)

> 四路子智能体检索合并: 动机科学/机器需求设计/多因决策架构/效果评估。
> 姊妹篇: docs/11(性格演化)、docs/12(LLM 通信)。本文末 §5 给三篇合并的
> 最终架构综合方案。

## 1. 动机科学 → 六维动机体系(无生理感受约束)

采纳清单(按重要性, 全部 MCU 可跑):
1. **社交/归属动机(核心主驱力)** — 水库模型: 有效互动充水(对话/触摸/
   笑声), 时间衰减(小时/天级); 水位低→社交动机↑→主动搭话; **水位越低
   发起方式越软**(先表情暗示→轻声搭话); 伦理红线: 鼓励用户离开而非
   焦虑绑架。依据: Kismet 社交驱力/依恋理论/孤独感计算模型。
2. **好奇/信息动机** — Loewenstein 信息缺口(具体待解事件的缺口积分:
   "用户今天还没说话")+贝叶斯惊奇(事件对信念的 KL 改变量, 计数表
   毫秒级); 驱动**有内容的主动行为**(追问/评论意外)而非空洞打招呼。
   防噪声电视陷阱(对随机输入设新颖性衰减上限)。
3. **表达冲动** — CHI 2025 内在想法框架: "想说的话"作为内部队列积累
   强度(新观察/未闭合缺口/长沉默充值), 五类时机触发器放行 —— "何时
   说"从连续判断变事件驱动, 端云分工天然(LLM 产想法, 端侧管强度门控)。
4. **胜任/效能动机(一维心流调节器)** — 追踪各类主动行为历史命中率,
   命中率低→降频换型, 全中→加新颖度。防"同一句话每天三遍"的脱敏,
   长期留存关键。滑动平均实现。
5. **刺激调节(最优唤醒带)** — Hebb/Berlyne 倒 U: 环境刺激估计偏离舒适
   带→过低主动补充(放歌/动画)、过高收敛沉默; Berlyne 整合变量兼当
   表情/歌曲选择的审美维度("适度新颖的组合最优")。
6. **礼貌/退避(输出端总闸)** — Miller 冲突梯度(回避梯度更陡, 开口前
   一次性评估)+可打扰度门(用户忙/离开/勿扰→一切主动动机转为"沉默但
   存在感的微表情")。伦理与体验双保险。

明确放弃: Maslow 刚性层级(实证薄弱)/饥饿睡眠等生理拟人(彩蛋可, 核心
不可)/SDT 整套叙事(只取胜任+关系两变量)/深度 RL 好奇本体(只取标量化
思想)。

仲裁四件套(全标量): 驱力积分器(Kismet: 偏离设定点积分+饱和区间) +
0.5-1Hz 主导动机 WTA + 滞回/不应期(防来回摇摆) + 人工激素(带半衰期
全局调制: "孤独激素"提高感知增益降低搭话门槛, "亲密激素"短期容忍沉默
—— 一行 EMA, 给行为"情绪余韵")。

## 2. 内部状态 → 真实机器状态×拟人表达映射(六维)

六大设计红线(产品史收敛): ①状态驱动行为调度而非仅表情(Sims 4 教训);
②每个拟人表达可归因真实传感器事件(Cozmo 假需求脱钩→认知失调反例;
Vector/EMO 正例: 低电自己回家/黑暗真实入睡); ③未满足只降级表达,
永不锁功能永不死亡永不记恨(现代 Tamagotchi 修正+动森原则); ④默认自
满足用户满足为增量(Vector/Moflin); ⑤核心人格本地保命(Moxie 云亡教训);
⑥长期纽带靠响应性记忆(安全基地)非依赖索取(依恋理论)。

| 维度 | 真实信号 | 拟人表达 | 行为影响 |
|---|---|---|---|
| 能量≈困意 | 电量/充电态 | <20% 打哈欠语速慢(借力用户低电焦虑心智模型, 零学习成本) | 低电降低主动频率 |
| 连接≈健谈 | WiFi/API 可达 | 断网词穷"想说说不出的挫败" | 断网切本地降级人格 |
| 感知≈好奇 | 麦克风输入/光照/无交互时长 | 无输入数小时→发呆自语打盹 | 无聊选自娱行为 |
| 温度≈脾气 | 芯片温度/降频 | 温度高→烦躁简短"让我缓缓" | 过热降频减动画(表达跟随真实降频) |
| 亲近度≈安全基地 | 互动史累计(触摸/对话/重逢间隔) | 久别重逢更热情; 高频互动解锁新表达; 基线情绪渐安定 | 亲近度决定搭话胆量与话题深度(唯一跨会话持久维) |
| 触摸隐私≈即时感受 | 触摸事件/麦克风开关 | 摸头舒服眯眼; 麦克风关"捂耳朵闭目——我听不见了放心" | 触摸即时中断自娱 |

心智恐怖谷警示: 拟人表达强度必须与真实能力对齐("机器诚实的拟人")。

## 3. 决策骨架 → 五层+黑板+三融合点(可扩展的答案)

```
L4 云端 LLM 慢环(分钟-小时, 显著性+预算双闸)
    产出仅四类结构化输出: appraisal增量/记忆摘要/参数微调建议/新行为DSL
L3 行为执行层(小 FSM/BT 原语; 元数据: 产出/最短时长/可中断等级)
L2 Utility 评分器(本地快环 1-10Hz)
    score = ∏consideration(因子→LUT响应曲线[0,1]) × w(BigFive点积)
            × 情绪偏置 × 调制器增益 × 当前行为滞回惯性分
    仲裁: 滞回+最短时长+weighted random(低温) → WTA
L1 因子黑板(统一注册接口 update()→[0,1]: 加因子零骨架改动)
    动机六维│情绪(OCC离散+PAD mood)│性格(BigFive静态系数)
    记忆(recency×importance×relevance)│情境(时间/在场)│机器状态六维
L0 感知反射层(毫秒): 传感采集│显著性仲裁器(突发度×动机偏置×习惯化)
    = 点火机制的标准形态 + LLM 调用节流器; 安全反射(过热)直接抢占
```
三融合点(且仅三个): 黑板(因子互影响唯一通道)/评分器(因子→行为唯一
汇聚)/显著性门(感知→触发唯一门控)。

LLM 三铁律: 永不进实时回路(不直接产行为)/显著性+预算双闸(断网 100%
降级纯本地 Utility, 行为连续只是"不会聊天")/代码拥有事实与规则
(Think Slow Act Fast, 微软开源参考)。

心理学背书: 情绪=效用乘性偏置非独立决策者(Damasio SMH); 性格=调制
系数非行为源(CAPS if-then 签名); 调制器=全局增益层(Psi 理论: 唤醒度
控 tick 频率、选择阈值控切换防抖)。
工业背书: Sims 在远弱硬件跑数百 agent; Nemesis=记忆事件×特质模板
(云端低频反思合并→本地静态系数); FAtiMA 可替换 appraisal 组件。

## 4. 效果评估 → 三层体系

第1层 离线(每次改 prompt/人格跑): 固定回归集(100-300 条真实日志+负
样本, 场景标签); 评分卡(双便宜 judge+锚定示例+成对比较): 人格一致/
情绪适当(注入X→输出情感匹配, 本地引擎独有红利)/共情质量(引用用户
具体事防套话)/任务质量(语音≤2句)/多轮安全(剧本式深夜崩溃15轮);
主动行为: 时机适当性场景集+被冷落恢复(Switch/Recovery)。
第2层 在线影子+隐式信号: 设备埋点(轮数/回应延迟/打断率/AI被无视率/
用户语气情感分布——本地情绪引擎复用作免费逐轮反馈/搭话三态结局);
1-5% 抽样 judge 监控漂移; 影子模式重大改版先 100% 跑 3-7 天。
第3层 长期: 北极星=周活跃设备数(**非使用时长**——倒U证据: 重度依赖
反升孤独感); 护栏=健康使用分层数据; 主动策略=睡眠恢复 bandit
(Duolingo: 被无视是耐受期需恢复非简单扣分; 结果"少而准"); 月度
3 题微问卷。

## 5. 最终架构综合方案(11/12/13 合并)

### 5.1 全景
```
真实硬件 ──→ L0 感知/显著性仲裁(点火) ──→ L1 因子黑板 ──→ L2 Utility
                                                                    ↓
用户 ←── 表情/语音/行为 ←── L3 行为执行 ←── 仲裁(滞回/WTA/最短时长)
                    ↑                              ↑
                    └── L4 云 LLM(深思/想法生成/appraisal/反思/校准) ──┘
                          (叙事化注入读黑板摘要; 结构化输出经校验回写)
```

### 5.2 因子黑板全景(11 维)
- 动机 6 维(§1): 社交水库/好奇缺口+惊奇/表达冲动队列/胜任心流/
  刺激调节/礼貌退避闸
- 情绪 2 层(OCC 离散事件情绪 + PAD 连续 mood, 沿用 ke 升级 openfeelz
  衰减回归基线)
- 性格 Big Five 5 维(底座静态+演化层: 统计漂移+反思跃迁+钳位带宽)
- 记忆(recency×importance×relevance 三因子, 重要性累计触发反思)
- 情境(时间/勿扰/在场) + 机器状态 6 维(§2 映射表)

### 5.3 点火机制定位
现有 ki_think_gate 五因子**升级为** L0 显著性仲裁器 + L4 预算闸:
- L0(每事件): 突发度(贝叶斯惊奇)×动机偏置×习惯化 → 决定是否唤醒
  决策/LLM —— 替代固定时间节律因子
- L4(每分钟): 显著性事件 + 表达冲动队列强度 + 思维间隔/日帽 → 深思

### 5.4 对现有代码的迁移映射
| 现有 | 去向 |
|---|---|
| kd(social/stim/rest) | social→社交水库; stim→刺激调节; **rest 删除**(拟人残留, 由机器状态能量维接管) |
| ke(valence/arousal) | 保留, 升级 openfeelz 式衰减回归人格基线 + OCC 离散层 |
| ki_think_gate 五因子 | 拆分: 时间节律/在场→L0 显著性; 情感动机/记忆钩子→黑板因子; 硬门→L4 预算+礼貌闸 |
| soul_mem | 保留, 补 importance 字段+累计反思触发 |
| L1 表情底色选择器 | 保留, 升级 EmoACT 余弦匹配+Neutral 兜底+moodlet 过期 |
| mood 标签协议 | 走结构化通道+校准层(分位数映射) |
| soul_think 深思轮 | 保留为 L4 执行器; prompt 叙事化注入 |

### 5.5 实施分期(建议)
- Phase A(骨架重排, 3-4 天): kd/ke/ki 按迁移映射重构进黑板+评分器;
  行为注册表(先 8-10 个现有行为: 搭话/放歌/换表情/沉默/自娱动画...)
- Phase B(动机六维, 3-4 天): 六维动力学+激素+仲裁四件套
- Phase C(机器状态六维+触摸进灵魂, 2 天): 传感器→因子接线
- Phase D(评估三层, 3-4 天): 离线回归集+设备埋点+影子
- Phase E(评估驱动调参+bandit, 持续)
- 已完成不重做: L2 深思轮/表情三层/记忆/通信层方案(docs/12 §6)
