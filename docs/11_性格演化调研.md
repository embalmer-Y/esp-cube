# 11 · 性格演化调研——脑科学/心理学理论 → 嵌入式技术映射(2026-11-13)

> 用户定案: Phase 2b 性格演化层需学术调研打底后再定技术栈。
> 本文档给出理论支柱 → 现有机制对照 → 三个技术方案候选, 供讨论。

## 1. 四大理论支柱

### 1.1 Whole Trait Theory(整体特质论, Fleeson 2010)
**核心: 特质 = 状态的密度分布。**
人格特质不是独立的"硬块", 而是日常行为/情绪状态的统计汇总——
外向者不是每刻都外向, 而是"外向状态出现的频率更高"。
- **对号入座**: 我们的 ke(情绪状态, 分钟级) 与性格向量(特质, 天/周级)
  正是 state/trait 二层; **"统计式演化"有精确理论原型**:
  trait = 近 N 天 state 的滑动分布均值。
- 来源: [Fleeson, The Relevance of Big Five Trait Content in Behavior](https://pmc.ncbi.nlm.nih.gov/articles/PMC2908394);
  [Ching et al. 2014](https://www.sciencedirect.com/science/article/abs/pii/S0092656613001293)

### 1.2 Generative Agents 反思机制(Park et al. 2023, Stanford)
**核心: memory stream + reflection + planning 三件套。**
Agent 记忆流按 recency/importance/relevance 检索; **周期性把记忆合成
更高层结论**("我开始喜欢音乐了, 因为和用户聊过很多次"), 形成思想层级
——反思改变后续检索与决策 → 性格涌现。
- **对号入座**: soul_mem(检索公式 recency+strength+match 同源!) +
  **"自省式演化" = reflection 的嵌入式版**; 我们 Phase1 的深思轮
  (ki_think_gate→LLM→intent) 已是反思的"行动版", 差"自我认知版"。
- 来源: [arXiv 2304.03442](https://arxiv.org/abs/2304.03442)

### 1.3 自由能原理/预测加工(Friston 2010)
**核心: 大脑最小化预测误差(surprise); 性格/信念=先验, 经验=贝叶斯
先验更新; 情绪是预测误差的评估信号。**
- **对号入座**: kd 的 error(驱力误差)天然映射 **surprise 信号**;
  ke reappraisal(已有)即评价理论(appraisal)实现;
  **性格演化 = 先验的慢速贝叶斯更新**——为"何时值得自省"提供
  触发判据(surprise 累积超阈 = 世界与预期偏差大 = 该更新自我模型)。
- 来源: [Friston 2010](https://www.uab.edu/medicine/cinl/images/KFriston_FreeEnergy_BrainTheory.pdf);
  [Bayesian brain theory 2025 综述](https://www.sciencedirect.com/science/article/abs/pii/S0306452224007048)

### 1.4 LLM 人格工程现状
- [Jungian 类型结构化人格控制(arXiv 2601.10025)](https://arxiv.org/html/2601.10025v1):
  显式心理类型建模 + 适应机制——"结构化 trait 向量+受控更新"的学术同路
- [Mem0](https://mem0.ai/library/agent-memory/how-to-add-long-term-memory-to-ai-companions):
  开源记忆层(云端为主, MCU 不适用但检索/分层思想可借鉴)
- 社区共识: 长期记忆 + 周期反思 → 人格涌现感; 难点是**身份漂移失控**
  (越用越不像自己)——所以需要底座钳位。

## 3. 技术方案候选(待讨论定案)

### 方案 A: 密度分布法(纯统计)
trait[5] ← 近 7 天 ke 状态的指数滑动均值(每维一个 EMA, 天级时间常数)。
- ✅ 零 LLM 成本/完全可解释/纯本地
- ❌ "性格=心情平均", 缺叙事感(说不出"我为什么变了")

### 方案 B: 反思生成法(纯 LLM)
触发(surprise 累积/重要记忆阈值) → LLM 读记忆摘要+当前 trait →
输出结构化 trait delta(+叙事 reason) → 钳位后施加。
- ✅ 性格变化有故事("常陪你听歌, 我更爱音乐了"); Generative Agents 实证
- ❌ LLM 成本; 依赖反思质量; 慢(天级才动一次)

### 方案 C: 混合双机制(推荐)
统计做底(A 的 EMA 无条件缓慢漂移) + 反思做跃迁(B 的关键事件驱动) +
L0 底座钳位(±带宽, 漂不出人设)。
- 理论对应: 心理学"日常习惯塑造 + 关键事件塑格"双通路
- 实现量: A 的 50 行 + B 挂现有深思轮(+200 行) + 钳位
- trait → 表达: 注入 system prompt("你最近 X 比明显, 因为...")
  + 映射点火参数(energy→proactivity 微调)
