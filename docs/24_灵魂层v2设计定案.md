### 0.1 R6 大原则落实口径(重要)

- **移除"生成类规则"**(产生行为的本地逻辑): 开机/重连播台反射(B2, `ESP_CUBE_SOUL_BOOT_RADIO`

  只由**用户指令**与 **LLM 深思**(读情绪/动机/记忆状态后自主决定 act or stay_silent)产生。
- **保留"约束类规则"**(限制行为而非产生): 预算/令牌桶/冷却/勿扰/用户停止锁存/ethics 闩锁/

- **表达层不受影响**: 底色表情(状态展示)/TTS 韵律/措辞 = R2 已裁的"调制器+表达层", 是显示不是决策。
- **连带后果**(定案): ① E3 习惯化从 L2 行为闸门迁移为"LLM 提议重复惩罚"概念(深思去重窗+
  行动级 recency 惩罚); ② test_soul_behavior 退役或改用途; ③ 深思预算重设计——L4 成为唯一
  自主来源后按行为类别分账(§4.4); ④ 断网=自主行为完全静默(用户直控保留), 与 docs/16 联网依赖一致;
  ⑤ 六维动机用途=触发深思(何时想)+prompt 状态叙事+表达层, 不喂本地行为评分。

## 2. 情感引擎 ke v2(A1/A2/A3)

### 2.1 三层栈: trait→mood→emotion(A1, D2 终案)

证据: WASABI 双质量弹簧(X 20s 回零/Y 慢回中) / ALMA 三层(情绪 20s 线性衰减, mood 迁移 10min,
"情绪偏置行为, mood 偏置认知") / AIBO pleasantness=水库区间满足度导出 / SDT+CUMS 实证
"持续剥夺→持续低落"(慢变量) / Joffily 自由能 valence=−dF/dt(快层变化率口径)。

```c
/* --- 慢层 mood(水平口径): 三水库满足度导出 --- */
s_i   = clampf((R[i] - L_i) / (H_i - L_i), 0, 1);      /* 舒适带 L=0.3/H=0.8 */
mu_v  = 0.5f * fminf(fminf(s_soc, s_stim), s_rest)     /* 最缺者主导 */
      + 0.5f * (s_soc + s_stim + s_rest) / 3.0f;
mu_v  = 2.0f * mu_v - 1.0f;                            /* →[-1,1] */
mood += (mu_v - mood) * (1.0f - expf(-1.0f / TAU_MOOD));  /* TAU_MOOD=7200~14400s */

/* --- 快层 emotion(变化率口径, 源锚保留): E2a 水平项撤出、迁入 mood --- */
v_fast = -1.0f * d_errsum + 2.0f * delta_emax_drop_impulse;   /* τ=4s 低通保留 */
if (v_fast < 0) v_fast *= 2.0f;                        /* 负性偏置(ROBIN 6.7x 上界取保守) */

/* --- 显示合成(WASABI ½(x+y) 结构) --- */
valence = clampf(0.65f * v_fast + 0.35f * mood, -1, 1);
/* mood 另任两职: 偏置快层诱发阈值(负 mood 时正冲量×0.7) + 表情底色(§2.3) */
/* arousal 维持 E1 冲量+回归(基线由 trait 调制, §3.2); urgency 可改 max(1−s_i)·w_i */
```

| 参数 | 值 | 依据 |
|---|---|---|
| TAU_MOOD | 7200~14400s(2~4h) | Sims moodlet 4h/ALMA 十倍/CUMS 数周上限 |
| 负性偏置 | ×2.0(负侧) | Paplu 0.02/0.003≈6.7 上界, 保守取半 |
| 快/慢权重 | 0.65/0.35 | WASABI 加权变体 |
| 舒适带 | L=0.3/H=0.8 | AIBO regulated range |

反例与约束: 纯水平口径致动机切换迟钝(Paplu 用户实测); 纯变化率口径与 CUMS/SDT 冲突且正是
30 天趋同病灶; mood 会随水库代谢贴底——期望行为(虐待组持续低落), 但须与 §2.3 死区联动防表情锁死。

### 2.2 ethics 闩锁解锁(A2)

证据: Davidson 恢复期一等公民 / Gross 重评恢复窗 ~2min / 皮质醇半衰 66-90min / Furby 喂食 10-15
次康复 / Tamagotchi 病可护理 / Sims moodlet 过期 / Vector "shut up"即退 chill。

```c
if (ethics_latched) {
    if (fabsf(v_rate_recent) < 0.5f)              /* 持续虐待时禁用衰减 */
        load *= (1.0f - 1.85e-4f);                /* τ=5400s, 皮质醇锚定 */
    if (soothe_accepted) load -= 0.20f;           /* 温和互动, ~12 次清完 2.5 */
    if (load <= 0.9f && latch_elapsed >= 1800.0f) {   /* 施密特: 0.36×L_ON + 最短30min */
        ethics_latched = false; relatch_immune = 1800.0f;  /* 解锁后30min免疫 */
    }
}
/* 守恒断言: accrual(|v|=1)=0.1−0.008 >> 1.85e-4 → 恶意等待无法刷解锁 */
/* 出厂兜底: 长按物理键≥5s → load=0(Tamagotchi reset 先例) */
```

### 2.3 表情底色映射(A3: 扇区+死区+强度+分档驻留)

证据: Russell 环形圆心=中性 / ROBIN(Paplu 2022)扇区边界=相邻词角中点, 16 人评估 67% 真实感 /
EmoACT 余弦>0.6 才选否则 Neutral+30s 同素材节流 / Sims moodlet 自带过期 / 宏表情自然时长 0.5-4s
(180s 一刀切驻留为极端反例)。

```c
/* 初始化: 24 素材按自身(v_k,a_k)算极角排序, 扇区=相邻角中点 */
theta_k = atan2f(a_k, v_k);
/* 每拍: 显示坐标含 mood 底色 */
vd = clampf(valence + 0.30f * mood, -1, 1);
ad = clampf(arousal + 0.15f * (mood > 0 ? 0 : -0.2f), -1, 1);
r = sqrtf(vd*vd + ad*ad);  th = atan2f(ad, vd);
if (r < R_NEUTRAL) cand = EXPR_NEUTRAL;            /* 死区: 圆心=中性脸 */
else cand = sector_lookup(th);                     /* Voronoi 兜底空扇区 */
variant = (r > R_SAT) ? V_INTENSE : V_BASE;        /* 强度分级 */
/* 切换: 分档驻留+裕度(替换 180s 一刀切) */
if (cand != cur) { hold_s++;
    if (hold_s >= T_MIN[cand] && cand_score(cand) > cand_score(cur) + 0.15f)
        { cur = cand; hold_s = 0; } } else hold_s = 0;
/* T_MIN: 高唤醒素材 8s/低唤醒 30s; 同素材重播节流 30s */
/* 无事件 45s 后回落 mood 底色脸(mood_idle_face) */
```

| 参数 | 值 | 依据 |
|---|---|---|
| R_NEUTRAL | 0.20 | Russell 圆心中性;EmoACT 0.6 阈折算 |
| R_SAT | 0.70 | WASABI 饱和区 |
| T_MIN | 8s(高唤醒)/30s(低唤醒) | 宏表情+WASABI+EmoACT 折中 |
| 裕度 | 0.15 | 施密特惯例 |
| 同素材节流 | 30s | EmoACT 原值 |
| 无事件回底色 | 45s | WASABI boredom 30-40s 起坡 |

### 3.3 双通道更新(B3)

**通道一·统计 EMA(Whole Trait Theory)**: 每日一步。
```c
delta = TR_EMA_ALPHA * (x[d] - tr[d]) + TR_SPRING_K * (tr_base0[d] - tr[d]);
/* 钳 |delta|≤0.05(§7.4); band 双保险; x[d]=当日状态密度均值(7日窗≥7样本) */
```
**关键: x[d] 用"减去 trait 预测基线后的残差密度"**(如 x[ENERGY]=日均(arousal−ke_arousal_base)

## 5. LLM 注入与校准(D1-D4)

### 5.1 prompt 布局(D1)

**对话轮**: system 三件套(身份 3 句/风格含 persona 4 维+短句规范/边界 Do-Don't 行为化条款) +
对话历史滑窗 + **尾部状态块 depth 0**(≤120 token): 首行"这是背景, 不是台词, 不要朗读或解释"
(防小模型过度表演——Sentipolis 实证 GPT-4o-mini 注入后可信度 −7~26%); 叙事三段式
`{事件},{感受},{想要}`; 强度 3 档(有点/挺/非常, 分位边界 0.33/0.66, 极端 5% 钳到"非常"——
E-STEER 倒 U); 变化 5 档 Δ 词表; **数值不进 prompt**(E-STEER: LLM 对连续数值不敏感); few-shot
2 条按状态桶每周轮换(RoleLLM: 对话锚定>形容词)。
**深思轮**: silent 为默认动作+配额可见+设备真随机 seed(打散行动聚集); 状态快照≤350 token
(情绪叙事+Δ+驱力+牵挂 top2+今日开口统计)。

### 5.2 结构化输出(D2)

运行时探测模式状态机: `json_schema strict`(百炼仅 qwen4-max/3.7+/3.8 系支持)→function calling
→`json_object`+容错。**不设 max_tokens**(百炼官方: 截断产生非法 JSON); 深思 schema 全字段
required+additionalProperties:false+enum 校验。MCU 容错解析 ~150 行: 首尾定界剥散文/括号栈补齐
截断/字段级降级(缺必需字段整包丢弃)/UTF-8 环缓冲(保留不完整多字节序列)/枚举校验/**
解析失败一律执行 silent 兜底**+遥测。thinking 模型+json_schema 的 content 空坑需实测。

### 5.3 soul_calib 校准层(D3)

per-model per-dimension 分位数校准器: 经验 CDF→目标分布逆 CDF; 目标分布=**引擎自身 delta
历史分布**(1Hz 引擎免费产生先验, Dirichlet 强度 50, min_samples=300 线性混合过渡); **只收原始
观测不收校准后值**(防自食)。置信三档按分位(<0.5/0.5-0.8/>0.8), 行动门限定义在校准后分位上。
漂移: PSI≥0.10 调查/≥0.25 再校准(10 分位); 注入↔回写↔行为三通道两两 Spearman ρ<0.77 告警
(Sentipolis judge 一致性下界); 换模型强制全量重置。

### 5.4 门禁+反自我强化(D4)

**promptfoo CI**: 27 用例(9 锚点状态×3 剂量)×每例 3 话术; judge 用异模型(与被测不同), 输出
{emotion_match, overacting, persona} 三子分 JSON, 均分≥7 且无单样本≤3 进门禁; 确定性断言
(JSON 合法率/枚举/长度/silent 基率带 [0.4,0.9])零成本阻断; 报告项(Distinct/置信分布/PSI/
before-after diff)。改 prompt 模板必跑+nightly 漂移监控; 20% 用例 held-out 防过拟合门禁集。
**mood 回写三断法**: 隔轮采纳(≤1/2 轮)+×0.5 衰减+与引擎预测方向校验(失配再×0.5); 最近 50 次
生效回写 AR(1)>0.8 → 暂停回写通道 24h(自增强统计指纹); 7 天失配率>40% 触发漂移告警。
**E-STEER 落法**: 风格形容词撤出状态块(文风全靠 few-shot); 状态信息以决策代价形式进深思轮
("社交水库低→say 预期收益高"); social_bond 用行为事实叙述("用户今天主动开话 3 次")不用数值。
reason 字段只作审计与 judge 输入, **不做自动惩罚源**(CoT 监控 obfuscation 风险)。
