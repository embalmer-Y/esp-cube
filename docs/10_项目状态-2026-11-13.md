## 1. 已完成功能

### 底座(B 系列)
- 音频全链: ES8311 codec + audio_mixer(ducking/混音) + NS4150B PA
- 网络电台 HLS 轮播 + NCM 点歌(app_ncm) + 播放器状态机(app_player)
- BT A2DP sink(仅 S31, P4 无控制器)
- 事件总线/分层架构(cubecore, docs/06 层级规则)

### 语音 AI(M1)
- 快线: qwen omni realtime WS(常驻语音进语音出, 失联自动回落)
- 慢线: paraformer ASR → qwen LLM(function calling 技能循环) → cosyvoice-v3-flash TTS
- 本地 filler 预合成回执("正在播放X"零等待)
- TTS 情绪调制: soul 语速/音高 hint → 每会话参数

### 助理服务(M2)
- SNTP 校时(ntp.aliyun.com) + 琐事 memo + 定时提醒带外播报(announce)
- LLM 技能 8 个: 点歌/电台/音量/停止/记事/提醒/清单/删除
- 口语时间→绝对时间(LLM 换算, system 注入当前时间)

### 灵魂内核(M3)
- kaleido drive/emotion/ignition 纯 C 移植(app_soul), 1Hz 编排
- mood 标签协议: LLM 回复尾 `<mood d>` → 情绪重评(EVT_SOUL_MOOD)
- 情节记忆: SD episodes 512 条跨重启持久化(实测 2 episodes 递增验收),
  检索注入(recency+strength+match top-3)+reinforce
- 主动交互框架 soul_think(勿扰/配额/冷静期, Kconfig 默认关, 待验收开启)

### 角色化 UI(M4, 已上手验收)
